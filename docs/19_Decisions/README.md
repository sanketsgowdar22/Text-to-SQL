# 19 — Architecture Decision Records (ADRs)

A log of architecturally significant decisions made during the project.

---

## What is an ADR?

An Architecture Decision Record captures the context, decision, and consequences of a significant technical choice. ADRs are immutable once accepted — if a decision is reversed, a new ADR is created referencing the original.

## Creating a New ADR

1. Copy [ADR_TEMPLATE.md](../16_Templates/ADR_TEMPLATE.md) to this directory
2. Name it `ADR-NNN_<title>.md` (e.g., `ADR-001_FASTAPI_SELECTION.md`)
3. Fill in all sections
4. Submit as part of a PR
5. Update this index
