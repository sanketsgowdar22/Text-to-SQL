# 06 — Task Documents

Individual task specification documents for granular implementation tracking.

---

## Conventions

- **Naming**: `TASK_<PHASE>_<ID>.md` (e.g., `TASK_AUTH_001.md`)
- **Template**: Use [TASK_TEMPLATE.md](../16_Templates/TASK_TEMPLATE.md) for every new task
- **Lifecycle**: Task documents are created BEFORE implementation begins
