# 16 — Document Templates

Reusable templates for creating standardized project documents.

---

## Available Templates

| Template | Usage |
|----------|-------|
| [PHASE_TEMPLATE.md](PHASE_TEMPLATE.md) | Creating new phase specification documents |
| [TASK_TEMPLATE.md](TASK_TEMPLATE.md) | Creating new task specification documents |
| [API_SPECIFICATION_TEMPLATE.md](API_SPECIFICATION_TEMPLATE.md) | Documenting new API endpoints |
| [ADR_TEMPLATE.md](ADR_TEMPLATE.md) | Recording architecture decisions |
| [TESTING_REPORT_TEMPLATE.md](TESTING_REPORT_TEMPLATE.md) | Summarizing test results |
| [REVIEW_REPORT_TEMPLATE.md](REVIEW_REPORT_TEMPLATE.md) | Documenting code review outcomes |
| [RELEASE_REPORT_TEMPLATE.md](RELEASE_REPORT_TEMPLATE.md) | Documenting release artifacts |

---

## How to Use

1. Copy the template file to the appropriate directory
2. Rename it according to the naming conventions
3. Fill in all sections — do not leave any section empty
4. Remove the instructional comments (lines starting with `<!-- -->`)
5. Submit for review before implementation begins
